# TinDog 🐕

A fun and modern dating app website for dogs! TinDog is a responsive, single-page application that brings dogs together to find love and companionship. Built with HTML, CSS, and Bootstrap.

Web Link: https://karanjthakur.github.io/tindog/

## 🌟 Features

- **Easy to Use**: Intuitive interface designed so even your dog could use it
- **Elite Clientele**: Access to all the best dogs in your area
- **Guaranteed Results**: Find the love of your dog's life or get your money back

## 📱 What's Included

### Sections

1. **Title Section** - Eye-catching hero section with call-to-action buttons for iOS and Android app downloads
2. **Features** - Highlights key benefits with icons
3. **Testimonials** - Carousel showcasing dog testimonials with images and location tags
4. **Press** - Logos from major tech and business publications
5. **Pricing Plans** - Three tiered pricing options:
   - **Chihuahua**: Free plan
   - **Labrador**: $49/month
   - **Mastiff**: $99/month (Premium)
6. **Call to Action** - Final conversion section
7. **Footer** - Social media links and copyright

## 🛠️ Technology Stack

- **HTML5** - Semantic markup structure
- **CSS3** - Custom styling (located in `css/` directory)
- **Bootstrap 5.3.3** - Responsive grid and components
- **Font Awesome** - Icon library
- **Google Fonts** - Montserrat and Ubuntu typefaces

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- No server setup required - this is a static website

### Usage

1. Clone the repository:
```bash
git clone https://github.com/karanjthakur/tindog.git
```

2. Navigate to the project directory:
```bash
cd tindog
```

3. Open `index.html` in your web browser:
```bash
open index.html
```

Or simply double-click the `index.html` file to open it in your default browser.
